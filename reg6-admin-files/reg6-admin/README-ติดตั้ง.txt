คู่มือติดตั้งระบบจัดการเนื้อหา (Supabase) - สำนักงานไปรษณีย์เขต 6
=================================================================

ระบบนี้เป็นเว็บสมัยใหม่ (HTML + JavaScript) ที่คุยกับ Supabase โดยตรง
ต้องเปิดด้วย Chrome / Edge / Firefox เวอร์ชันใหม่ ไม่ใช่ IE และไม่ต้องรันบน Windows Server 2008
ต้องต่ออินเทอร์เน็ตได้ (โหลดไลบรารี supabase-js จาก cdn.jsdelivr.net และเชื่อมต่อ Supabase)

ขั้นตอนตั้งค่า Supabase (ทำครั้งเดียว)
------------------------------------
1) เปิด Supabase Dashboard > SQL Editor > New query
   วางเนื้อหาไฟล์ supabase_schema.sql ทั้งไฟล์ แล้วกด Run
   (สร้างตาราง + ข้อมูลเริ่มต้น + ระบบสิทธิ์ รันซ้ำได้ ไม่ลบข้อมูลเดิม)
   จากนั้นเปิด query ใหม่ วางไฟล์ supabase_step2_server_sync.sql แล้วกด Run
   (เปิดสิทธิ์ "อ่านอย่างเดียว" เฉพาะข้อมูลที่แสดงบนเว็บให้เซิร์ฟเวอร์เว็บดึงไปสร้าง content.js เองได้
    และสร้างฟังก์ชัน site_content_js()  การเพิ่ม/แก้/ลบ ยังทำได้เฉพาะผู้ดูแล)

2) สร้างบัญชีผู้ดูแล
   Authentication > Users > Add user > Create new user
   ใส่อีเมลและรหัสผ่าน แล้วติ๊ก "Auto Confirm User"

3) ปิดการสมัครสมาชิกเอง (สำคัญ)
   Authentication > Sign In / Providers > ปิด "Allow new users to sign up"

4) ให้สิทธิ์บัญชีนั้นเป็นผู้ดูแล
   กลับไปที่ SQL Editor รันคำสั่งนี้ (เปลี่ยนอีเมลให้ตรงข้อ 2):
       insert into public.admin_users (user_id)
       select id from auth.users where email = 'admin@example.com';
   บัญชีที่ไม่อยู่ในตาราง admin_users จะเข้าระบบไม่ได้ แม้ล็อกอินผ่าน

การเปิดใช้งานหน้าจัดการ
----------------------
ไฟล์ index.html, app.js, style.css, config.js ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (แนะนำ HTTPS) เลือกวิธีใดวิธีหนึ่ง:
 ก) ฝากบนเว็บโฮสต์แบบ static (เช่น Netlify, Cloudflare Pages, GitHub Pages) หรือ IIS บนเครื่องที่ทันสมัย
 ข) ทดสอบบนเครื่องตัวเอง: เปิด Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์
        python -m http.server 8080
    จากนั้นเปิด http://localhost:8080

ข้อมูลเชื่อมต่อ Supabase อยู่ในไฟล์ config.js (ใส่ Project URL และ publishable key ให้แล้ว)
- publishable key ใส่ในโค้ดฝั่งเบราว์เซอร์ได้ ความปลอดภัยอยู่ที่สิทธิ์ในฐานข้อมูล (Row Level Security)
  ซึ่งตั้งให้เฉพาะผู้ดูแลที่อยู่ใน admin_users เท่านั้นที่อ่าน/เขียนได้ ผู้ใช้ทั่วไปเข้าถึงตารางไม่ได้เลย
- ห้ามใส่ secret key หรือ service_role key ในไฟล์ใด ๆ ของระบบนี้

การใช้งานประจำวัน
-----------------
1) เข้าสู่ระบบด้วยอีเมล/รหัสผ่านของผู้ดูแล
2) เพิ่ม แก้ไข ลบ ข้อมูลในเมนูต่าง ๆ (ข่าว หนังสือเวียน ระบบ/คู่มือ เบอร์โทรศัพท์ ส่วนงาน Dashboard)
3) กดบันทึกแล้วเสร็จ เซิร์ฟเวอร์เว็บ (Windows Server 2008) จะดึงข้อมูลใหม่มาอัปเดตเว็บเองภายในประมาณ 5 นาที
   (ตั้งค่าตามคู่มือในชุด reg6-web โฟลเดอร์ sync)
4) ถ้าต้องการอัปเดตทันที หรือเซิร์ฟเวอร์ซิงก์เองไม่ได้ ใช้เมนู "ส่งออกไปยังเว็บไซต์"
     - "สร้างและดาวน์โหลด content.js" แล้วนำไปวางทับในโฟลเดอร์ js ของเว็บไซต์ หรือ
     - "สร้างและบันทึกลงโฟลเดอร์เว็บโดยตรง" (Chrome/Edge: เลือกไฟล์ js\content.js บนไดรฟ์ที่ map ไปยังเซิร์ฟเวอร์เว็บ)
   แล้วเปิดเว็บกด Ctrl+F5

ข้อควรรู้
---------
- รูปโปสเตอร์ข่าวและไฟล์แนบหนังสือเวียน ยังไม่อัปโหลดผ่านหน้าจัดการ ให้คัดลอกไฟล์ไปไว้ในเว็บไซต์เองแล้วพิมพ์ชื่อไฟล์/ลิงก์
- สำรองข้อมูล: Supabase Dashboard > Database > Backups (หรือ export ตารางเป็น CSV เป็นระยะ)
- ถ้าเปลี่ยนรหัสผ่านผู้ดูแล: Authentication > Users > เลือกบัญชี > Send password recovery หรือตั้งรหัสใหม่
